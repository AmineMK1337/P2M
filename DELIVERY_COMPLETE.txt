PIPELINE ARCHITECTURE:
━━━━━━━━━━━━━━━━━

Every 5 seconds (indefinite loop):

  STAGE 1: CAPTURE (5 seconds)
    • Tool: sudo tcpdump
    • Interface: enp0s8 (attacker → victim)
    • Output: /data/test1/simulated_attack.pcap
    • Behavior: Captures raw network packets

  STAGE 2: EXTRACT (0.5-2 seconds)
    • Tool: CICFlowMeter sniffer
    • Input: PCAP from Stage 1
    • Output: /data/test1/output_<timestamp>.csv
    • Content: ~80 network flow features per row

  STAGE 3: INFER (0.1-0.5 seconds)
    • Tool: PCA ML model (joblib)
    • Input: Feature CSV from Stage 2
    • Process: Reconstruction error → anomaly score
    • Output: Predictions with confidence scores

  STAGE 4: MITIGATE (0.1-0.3 seconds)
    • Tool: Classification & Mitigation agents
    • Input: Attack predictions from Stage 3
    • Output: /logs/alerts.log + iptables rules
    • Action: Block malicious IPs automatically

Total per cycle: ~5-8 seconds (mostly Stage 1 fixed time)


EXECUTION GUARANTEES:
━━━━━━━━━━━━━━━━

✓ Fixed 5-second cycle boundary (enforced)
✓ Stages execute sequentially (no overlap)
✓ One cycle completes before next starts
✓ Deterministic behavior (same input → same output)
✓ Resilient error handling (failures don't halt pipeline)
✓ Comprehensive logging (every action recorded)
✓ No LLM in hot path (deterministic agents only)
