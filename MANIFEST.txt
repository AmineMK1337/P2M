================================================================================
WHAT THE SYSTEM DOES
================================================================================

The Pipeline Orchestrator is a micro-batching engine that runs indefinitely
on the gateway VM, executing a 5-second cycle that:

CYCLE FLOW:
  1. CAPTURE STAGE (5 seconds)
     • Uses tcpdump to capture traffic on enp0s8 (attacker interface)
     • Output: /data/test1/simulated_attack.pcap

  2. EXTRACT STAGE (0.5-2 seconds)
     • Processes PCAP through CICFlowMeter
     • Extracts ~80 network features per flow
     • Output: /data/test1/output_<timestamp>.csv

  3. INFER STAGE (0.1-0.5 seconds)
     • Runs PCA ML model for anomaly detection
     • Calculates reconstruction error (anomaly score)
     • Classifies flows as benign (1) or attack (-1)
     • Output: Predictions + confidence scores

  4. MITIGATE STAGE (0.1-0.3 seconds)
     • Classification agent processes predictions
     • Mitigation agent applies iptables rules for attacks
     • Logs all alerts to /logs/alerts.log
     • Output: Blocked IPs + security alerts

TOTAL: 5-8 seconds per cycle, runs indefinitely

STOP:

  • Should see stage completion marks (✓)
  • Should see no ERROR messages

STEP 4: Generate test attack
  hping3 -S --flood -p 80 <victim-ip>

STEP 5: Verify detection
  grep "[ALERT]" /logs/alerts.log
  # Should show attack detection

STEP 6: Verify mitigation
  sudo iptables -L -n | grep DROP
  # Should show attacker IP blocked
